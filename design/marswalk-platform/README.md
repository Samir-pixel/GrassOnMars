# Marswalk — Grass on Mars 🌱

Платформа для NASA Space Apps 2026, челлендж «Interplanetary Survival Guide: Martian Map».
Команда Grass on Mars, Душанбе.

**Что это.** Платформа поддержки решений для первых экипажей на Марсе. Сценарий:
глобус Марса → выбор точки → анализ данных → рекомендация → маршрут → результат выхода.

1. **Overview.** 3D-глобус с 14 реальными местами. Для каждого: проверка ограничений
   (широта ±50°, высота ниже +2 км по исследованиям NASA о местах посадки людей), пять
   измеримых параметров с источником, индекс пригодности и объяснение ранга от Zyro.
2. **Compare sites.** Три профиля миссии (база с оранжереей, безопасная посадка,
   астробиология) или свои веса. Таблица рейтинга и разбор, почему #1 выше #2.
3. **Marswalk (Езеро).** Слои данных, 4 варианта маршрута с ранжированием, вердикт
   GO / NO GO, навигация шаг за шагом, контроль кислорода и возврата, отчёт о выходе.
4. **Method.** Проблема, соответствие челленджу, данные NASA, модели и ограничения.

**Zyro** — персонаж и ИИ-ассистент. Все его реплики и ответы в одной панели чата
(кнопка «Ask Zyro»). На claude.ai отвечает через Claude, вне claude.ai — готовыми
ответами по данным приложения. Изображения — `data/nova/`.

## Запуск

```bash
python -m http.server 8000   # в папке проекта, затем http://localhost:8000
```
Ничего ставить не нужно: текстура Марса и демо-рельеф встроены в `js/assets.js`.
Для одной ссылки или флешки есть `dist/marswalk.html` — весь сайт в одном файле.

## Публикация на GitHub Pages

Залейте папку в репозиторий → Settings → Pages → ветка `main`, папка `/`.
Онлайн дополнительно заработает слой «Trek imagery» (тайлы NASA Mars Trek).

## Чек-лист на хакатон

1. **Настоящий рельеф.** Скачайте HiRISE DTM Езеро и запустите
   `python tools/prepare_terrain.py --dtm файл.tif --out data/terrain.json`.
   Сайт сам подхватит файл, плашка «Demo terrain» исчезнет.
2. **Координаты целей** в `js/sites.js` (TARGETS) примерные — сверьте с Mars Trek и CRISM.
3. **Погода.** Значение пыли τ в настройках — пример. Подставьте данные MEDA.
4. **Проверьте цифры мест** (высоты MOLA, оценки воды) и при необходимости поправьте в `js/sites.js`.
5. После правок: `python tools/build_single.py`, чтобы обновить однофайловую версию.

## Как показать на защите (3 минуты)

1. Enter mission control. Покрутить глобус, открыть Arcadia: параметры, источники, ранг.
2. Открыть Phoenix или Olympus Mons: исключены ограничениями, Zyro объясняет почему.
3. Compare sites: переключить профиль на Astrobiology, лидер меняется на Jezero.
   Показать разбор «почему #1 выше #2». Подвигать вес воды.
4. На Jezero «Plan a Marswalk here». Четыре варианта, рекомендован Safest, и почему.
5. Start navigation. Затем «Contingency: suit leak» → предупреждение → Turn back →
   отчёт о выходе.
6. Method: какие данные NASA где используются и где ограничения прототипа.

## Научные допущения (вынесены во вкладку NASA data)

- Давление: P ≈ 610 Па × e^(−h / 11,1 км), h — высота по MOLA.
- Индекс пригодности = Σ вес × параметр (вода, свет, давление, рельеф, наука), веса зависят от профиля миссии.
- Ограничения: |широта| ≤ 50°, высота ≤ +2 км (NASA Human Landing Sites workshop, 2015).
- Скорость в скафандре: правило Тоблера × 0,6. Склоны круче лимита непроходимы.
- Запас кислорода 30%, возвращение до 17:30 LMST, пыль τ ≥ 2 — отмена выхода.
- Доза радиации: 0,67 мЗв в сутки (Curiosity RAD).

## Источники

Текстура глобуса: NASA 3D Resources (github.com/nasa/NASA-3D-Resources), глобальная мозаика Viking.
Тайлы: NASA/JPL Mars Trek. Библиотеки: three.js, Leaflet, Lucide.

Код подготовлен с помощью Claude (Anthropic). Если правила Space Apps просят указать
использование ИИ, отметьте это в форме проекта.

## Обновление: карта, фото, погода, голос

- **Глобус в 4K.** Цветная карта 4096×2048 и карта нормалей рельефа из проекта Celestia
  (собраны из данных USGS Viking и Mars Global Surveyor) — `data/mars_color_4k_celestia.jpg`,
  `data/mars_normal_2k_celestia.png`. Пересборка: `python tools/make_assets.py`.
- **Слои и фильтры на глобусе.** Несколько тем сразу, кнопка «Layers»: подписи, посадочные
  аппараты, исключённые места, «только с фото», легенда значков.
- **Фото и итоги экспедиций** — `js/content.js` (PHOTOS, EXPEDITIONS). Номера PIA проверены
  по NASA Photojournal. Превью грузятся с серверов NASA, когда сайт размещён в интернете
  (на claude.ai внешние картинки заблокированы, там показывается ссылка на Photojournal).
- **Погодный близнец на Земле** — высота в стандартной атмосфере Земли с тем же давлением,
  измерения метеостанций (MEDA, REMS, Viking) и место на Земле с похожими условиями
  (`EARTH_TWINS`, `STATIONS`).
- **Голос Zyro** — выбор голоса в шапке чата; по умолчанию «rounded». На claude.ai это голоса
  Claude, в других браузерах — системный мужской голос.

## Обновление: настоящая карта Езеро и звёзды

- `tools/fetch_jezero.py` — снимки HiRISE (≈1,2 м/пикс.) и CTX (≈5 м/пикс.) и настоящий рельеф
  (HiRISE + HRSC) для режима Marswalk. Результат: `data/jezero_*.jpg`, `data/terrain.json`, `js/jezero_data.js`.
  Тайлы взяты из открытого проекта Jez Explore; у репозитория нет файла лицензии — перед сдачей
  согласуйте с автором или пересоберите из мозаики USGS (doi:10.5066/P13CPYYU).
- `js/stars.js` — 9 096 звёзд Yale Bright Star Catalog (NASA HEASARC) для неба за 3D-глобусом.
